How to prepare your thesis repository with Git

Every thesis I supervise lives in a Git repository on GitHub. It keeps your work safe, lets me follow your progress and makes your results reproducible. This page explains how to create the repository and how to organize it.

1. Create the repository

  1. Go to GitHub and create a free account, if you do not have one already.
  2. Create a new private repository named <currentYear>-<surname>-<oneOrTwoKeywords>, where the keywords identify the topic of your thesis.
    Example: 202X-ghioldi-CSPRDE
  3. Invite me as a collaborator (Settings → Collaborators → Add people): use the account fghio or the email address federico.ghioldi@polimi.it.

2. Folder structure

Clone the repository on your computer and create the following four folders inside it:

202X-ghioldi-CSPRDE/
├── biblio/
│   ├── README.md
│   ├── smith2021-hydrogen-flames.pdf
│   └── ...
├── OpenFOAM-thesis/
│   └── src/
│       └── reactionModels/
│           └── myNewCombustionModel/
├── data/
│   ├── fig1.py
│   ├── fig1_data.csv
│   └── ...
└── thesis/
    ├── main.tex
    ├── bibliography.bib
    └── figures/

Warning: empty folders cannot be pushed to the remote repository, so the other users with access to it will not see them. To push a folder that is still empty, add an empty file named .gitkeep inside it.

3. What goes in each folder

biblio

All the papers (in PDF format) that are fundamental for your research. Papers can be uploaded with your comments, notes, highlights, etc.

The folder must contain a README file, kept up to date, listing the most relevant papers and why they matter: for each relevant paper in biblio, add a very short description (2–3 lines at most). For example:

# Key references

- smith2021-hydrogen-flames.pdf
  LES of lean premixed hydrogen flames. Reference for the mesh
  resolution and the validation data used in Chapter 3.

OpenFOAM-thesis

This folder must NOT contain OpenFOAM. It must contain only the new models or developments you produce during your thesis, if any.

The models you develop must follow the folder structure of OpenFOAM. For example, if you create a new combustion model, OpenFOAM-thesis will contain only the path src/reactionModels/<newModel>.

data

All the data needed to create the figures of your thesis, together with the Python scripts used to produce the plots. The name of each script must make it clear what it produces (e.g. fig1.py for Figure 1 of the thesis).

The folder must not exceed 100 MB. If your data are larger, do not upload them: upload only the scripts. I will give you specific instructions on how to handle large data.

thesis

All the .tex and .bib files, plus the figures folder, needed to compile your thesis. The choice of style and format is up to you. I recommend the article format of the template provided by Politecnico di Milano; for the title page, use the book format of the same template.

4. Basic Git commands

If you have never used Git, these are the commands you need every day (replace the repository name with yours):

git clone https://github.com/<yourUsername>/202X-ghioldi-CSPRDE.git
cd 202X-ghioldi-CSPRDE

git add .                                  # stage your changes
git commit -m "Short description of the change"
git push                                   # send them to GitHub
git pull                                   # get the latest version

More information on how to write the thesis is available in How to write your thesis.
