Introduction

Projects are longer works told in several posts, like this series. They are organised in three levels: the list of projects, the list of posts of a project, and the single post.

Three levels, three pages

  • projects.html: one card per project, with image, category and summary;
  • projectArchive?id=WEB: the timeline of the posts of a project;
  • projectPost?project=website&post=overview: a single post.

The first page is written by hand. The other two are templates that load their content from posts/projects/: 

posts/projects/
├── website.html          timeline of this project
└── websitePosts/
    ├── overview.html
    ├── hosting.html
    └── ...

The list of posts

projectArchive.html maps the short id of each project to the file with its timeline. Adding a project means adding one line here: 

if (cardId === 'WEB') {
  contentDiv.innerHTML = "<div data-include='./posts/projects/website'></div>";
} else if (cardId === 'OF') {
  contentDiv.innerHTML = "<div data-include='./posts/projects/CFDcourse'></div>";
}

The timeline itself is a simple list of dated entries, each linking to a post. Posts that are planned but not yet written can be listed without a link, as a roadmap.

The post and its table of contents

projectPost.html works like the page of a blog post: it reads project and post from the address and loads posts/projects/<project>Posts/<post>.html.

The table of contents in the left column is built automatically by tableContent.js from the headings of the post. Each heading carries an anchor, and the script numbers the sections, links them, and highlights the section being read while scrolling: 

<h2 id="Archive" style="scroll-margin: 1em;">
  <a href="#Archive" class="headerlink" title="Archive"></a>
  The list of posts
</h2>
