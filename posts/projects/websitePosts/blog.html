Introduction

The blog has a list of posts with cards and pages, a page for each post and a page of tags. There is no database and no build step: a post is an HTML file, and a small JSON file lists the posts.

A post

Each post is a file in posts/blog/. Besides the text, it carries its own metadata (title, dates, tags, description) in a data-metadata attribute, so that the list, the tags and the search can read them without a separate file: 

<article class="card-content article" data-metadata='{
  "creationDate": "2024-11-23",
  "lastModificationDate": "2024-11-24",
  "title": "collectify: gotta collect &apos;em all",
  "readTime": "5 min",
  "tags": ["python", "app", "utility"],
  "description": "The tool for collectors."
}'>
  <!-- text of the post -->
</article>

The list of posts

A static website cannot list the files of a folder, so the posts are listed in posts/blog/index.json: 

[
  { "name": "collectify.html" },
  { "name": "tex2html.html" }
]

Publishing a new post therefore takes two steps: add its HTML file, and add its name to this list. blogCard.js reads the list, loads the metadata of each post, sorts the posts from the most recently updated, and builds the cards, four per page, with pagination.

The page of a post

All posts are shown by the same page, blogPost.html, which reads the name of the post from the address and loads its file into the central column: 

// blogPost?post=collectify  ->  posts/blog/collectify.html
var post = new URLSearchParams(location.search).get("post");
$.ajax({ url: "./posts/blog/" + post + ".html" })
  .done(function (html) { $(".column-main").html(html); });

Tags

The tags page collects the tags of all posts from their metadata and shows them as buttons; tagArticles?tag=python lists the posts with that tag. Since collecting the tags means reading every post, the result is kept in the session storage and reused while the tab is open.

Comments

The comments at the bottom of the posts are provided by Disqus, an external service: each post includes a short script with its own address and identifier, and Disqus does the rest.
