Introduction

The magnifying glass in the navigation bar (or the keys / and Ctrl+K) opens a search over the whole website: blog posts, project posts, theses, the CV, publications and contacts. Search engines for websites usually need a server; here the browser does everything.

Building the index

The first time the search is opened, search.js downloads the pages listed in its sources, extracts their text, and builds an index: a list of documents, each with a title, a type, some tags, the text and the address to open. 

{
  type: "Project",
  section: "How to make this website",
  title: "How to make this website: site search",
  text: "The magnifying glass in the navigation bar ...",
  url: "projectPost?project=website&post=search"
}

New content is found automatically: blog posts from index.json, theses from their cards, project posts from the links in each project's timeline. Only a brand-new project has to be added to the list of sources.

The index is saved in the session storage, so it is built once per tab: the following searches are instantaneous.

Fuzzy matching

The matching is done by Fuse.js, a small library for fuzzy search: it tolerates typos and partial words, and ranks the results. Each field has a weight, so that a match in the title counts more than a match in the text: 

new Fuse(docs, {
  keys: [
    { name: "title",   weight: 3 },
    { name: "tags",    weight: 1.5 },
    { name: "section", weight: 1 },
    { name: "type",    weight: 1 },
    { name: "text",    weight: 1 }
  ],
  includeMatches: true,   // to highlight the matching words
  ignoreLocation: true,   // a match anywhere in the text is fine
  threshold: 0.3          // how fuzzy: 0 = exact, 1 = anything
});

Fuse.js is loaded only when the search is opened for the first time, so it costs nothing to visitors who never use it.

Opening a result

Each result links to its page. Some results also carry a hint for the page they open: a thesis opens theses?q=<title>, which shows that thesis only, and a CV entry opens the curriculum scrolled to the right section.

Keyboard

The search is usable without the mouse: / or Ctrl+K (Cmd+K on a Mac) opens it, the arrows move through the results, Enter opens the selected one and Esc closes it.
