Introduction

The moon icon in the navigation bar switches the website to a dark theme, and the choice is remembered for the next visits. This post explains how it works.

Redefining the variables

Since all colours are CSS variables (see layout and theme), the dark theme is mostly a second set of values for the same variables, applied when the <html> element has the class dark: 

html.mx.dark body {
  --accent: #9dbcf0;      /* a lighter blue, readable on a dark background */
  --accent-soft: rgba(157, 188, 240, 0.13);
  --bg: #18181b;
  --text: #e4e4e7;
  --text-muted: #a1a1aa;
  --border: #303036;
}
html.mx.dark { background: #18181b; color-scheme: dark; }

Every element that uses the variables changes colour by itself. Only a few elements need a specific rule, for example images with a white background or embedded maps.

The dark theme uses neutral greys rather than dark blues: they are easier on the eyes, and they do not clash with photos. The accent blue is lighter than in the light theme, to keep enough contrast.

The switch

The switch saves the choice in the browser's local storage, which, unlike the session storage, survives when the browser is closed: 

function applyNight(on) {
  document.documentElement.classList.toggle("dark", on);
}
toggle.addEventListener("click", function () {
  var on = !document.documentElement.classList.contains("dark");
  applyNight(on);
  localStorage.setItem("night", on);
});

Applying the theme early

The saved choice is applied by a one-line script at the very top of the <head> of each page, before the stylesheets. In this way the page is drawn directly with the right theme: 

<script>
  try {
    if (localStorage.getItem("night") === "true")
      document.documentElement.classList.add("dark");
  } catch (e) {}
</script>

The try block matters: in some private windows the local storage is not available, and the page must still work, simply in the light theme.
