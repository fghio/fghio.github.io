Introduction

The moon icon in the navigation bar switches the website to a dark theme, and the choice is remembered for the next visits. Thanks to the colour variables introduced in layout and theme, the dark theme is mostly a second list of values. In this post we write that list, the switch, and the few lines that apply the saved choice when a page opens.

A second set of values

The dark theme is active when the <html> element has the class dark. Under that class, the same variables get new values: 

html.mx.dark body {
  --accent: #9dbcf0;                       /* a lighter blue, readable on dark */
  --accent-hover: #c0d4f7;
  --accent-soft: rgba(157, 188, 240, 0.13);
  --bg: #18181b;
  --card-bg: #18181b;
  --text: #e4e4e7;
  --text-muted: #a1a1aa;
  --border: #303036;
}

html.mx.dark {
  background: #18181b;
  color-scheme: dark;    /* dark scrollbars and form controls */
}

Every element that uses the variables changes colour by itself: cards, links, tags, code blocks, tables. This is the main payoff of defining colours as variables.

Choosing the colours

  • Neutral greys, not dark blue. A blue-tinted background tints everything, including photos; neutral greys stay out of the way.
  • Not pure black. #18181b instead of #000, and light grey text instead of pure white: the contrast is still high, but less harsh.
  • A lighter accent. The navy blue of the light theme is unreadable on a dark background, so the accent becomes a light blue. Buttons with an accent background then need dark text, defined by another variable (--on-accent).
  • Borders instead of shadows. Shadows are invisible on a dark background; thin borders keep the cards separated.

The exceptions

A few elements do not use the variables and need a specific rule: images with a white background (logos, diagrams), embedded content such as the map, and some boxes of the base theme with hard-coded colours. For example: 

/* boxes of the base theme: let the card colour show through */
html.mx.dark body .box { background: transparent; }

The switch

The switch is a link with an icon in the navigation bar. Clicking it toggles the class and saves the choice in the local storage, which, unlike the session storage, survives when the browser is closed: 

<a class="navbar-item night" id="night-nav" title="Switch Color Scheme" href="javascript:;">
  <i class="fas fa-moon" id="night-icon"></i>
</a>
function applyNight(on) {
  document.documentElement.classList.toggle("dark", on);
  // swap the icon: moon in light mode, sun in dark mode
  document.getElementById("night-icon").className = on ? "fas fa-sun" : "fas fa-moon";
}

document.getElementById("night-nav").addEventListener("click", function () {
  var on = !document.documentElement.classList.contains("dark");
  applyNight(on);
  localStorage.setItem("night", on);
});

Following the system setting

Operating systems have their own light/dark preference, exposed to CSS and JavaScript as prefers-color-scheme. This website starts in the light theme and lets the visitor choose, but you can use the system preference as the default when nothing has been saved yet: 

var saved = localStorage.getItem("night");
var on = saved !== null ? saved === "true"
                        : matchMedia("(prefers-color-scheme: dark)").matches;

Applying the choice when a page opens

The saved choice must be applied on every page, and as early as possible: the page should be drawn directly with the right theme. The place is the very top of the <head>, before the stylesheets, in a one-line script: 

<head>
  <script>
    try {
      if (localStorage.getItem("night") === "true")
        document.documentElement.classList.add("dark");
    } catch (e) {}
  </script>
  <link rel="stylesheet" href="assets/css/default.css">
  <link rel="stylesheet" href="assets/css/modern.css">
  ...

Two details matter. The script acts on <html>, which already exists when the <head> is parsed, while <body> does not exist yet. And the try block keeps the page working in private windows where the local storage is not available: the page then simply opens in the light theme.

The script is inline rather than in a separate file on purpose: a separate file would have to be downloaded before running, while an inline script runs immediately.

Try it yourself

  1. Add the dark values of your variables under html.mx.dark body.
  2. Add class="dark" to <html> by hand and look for elements that do not change: give them a rule or make them use a variable.
  3. Add the switch and the early script, then check that the choice survives a reload and a browser restart.
