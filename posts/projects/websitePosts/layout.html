Introduction

All the pages of this website share the same structure: a navigation bar, three columns and a footer. This post describes how the layout is built and how the style is organised, so that changing a colour or a font means editing one line.

Bulma and the base theme

The layout uses Bulma, a CSS framework based on flexbox, through a stylesheet (default.css) adapted from the Icarus theme. Bulma describes the layout with classes: a columns container and one column per column, with their width at each screen size. 

<section class="section">
  <div class="container">
    <div class="columns">
      <div class="column column-main order-2 is-8-tablet is-8-desktop is-6-widescreen">
        <!-- content -->
      </div>
      <div class="column column-left order-1 is-4-tablet is-4-desktop is-3-widescreen">
        <div id="leftPaneContainer"></div>
      </div>
      <div class="column column-right order-3 is-4-tablet is-4-desktop is-3-widescreen">
        <div id="rightPaneContainer"></div>
      </div>
    </div>
  </div>
</section>

The central column comes first in the HTML, because it is the most important content, but the order-* classes display it between the two side columns. On a wide screen the widths are 3 + 6 + 3 twelfths; on smaller screens the right column moves below, and on a phone all the columns stack.

A separate stylesheet for the restyle

Instead of editing the base theme, all the visual choices are in a second stylesheet, modern.css, loaded after it. Keeping them apart has two advantages: the base theme can be updated or replaced, and the whole restyle can be switched off by removing one line.

To make sure the new rules win over the old ones without sprinkling !important everywhere, every rule starts with html.mx, a class added to the <html> element of each page. The extra class gives the new rules a higher priority (specificity) than the theme's. 

<html lang="en" class="mx">

Colours and fonts as variables

Colours, font, corner radius and shadows are defined once, as CSS variables, and used everywhere else. Changing the accent colour of the whole website is a one-line change. 

:root {
  --accent: #1a3a6e;        /* PoliMi navy */
  --accent-soft: #e7edf7;
  --bg: #ffffff;
  --text: #1f2633;
  --text-muted: #5b6475;
  --border: #e3e7ee;
  --radius: 6px;
  --font-body: "Inter", system-ui, -apple-system, "Segoe UI", sans-serif;
}

html.mx body a { color: var(--accent); }
html.mx body .card { border: 1px solid var(--border); border-radius: var(--radius); }

The same variables are redefined for the dark theme, which is why the dark mode needs no extra rules for most elements (see dark mode).

The style

The style is deliberately minimal: a single sans-serif font (Inter), one accent colour, thin borders instead of shadows, generous white space, and a consistent type scale. Cards, CV entries, tags and buttons are all built from the same few variables, which keeps the pages consistent with each other.

Phones

Below 769 px the navigation bar wraps onto two lines, the CV entries put the dates above the text instead of beside it, and the side columns move below the content. These rules are in the same stylesheet, inside @media blocks, next to the rules they adapt.
