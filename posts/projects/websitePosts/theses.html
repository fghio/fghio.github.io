Introduction

The theses page lists the M.Sc. theses I offer, with a search box, a filter for the available ones and a counter. Before writing an e-mail, students are guided to fill in a short form. In this post we build the cards, the filters and the dialog.

The cards

All the theses are in a single file, thesis-card.html, loaded into the page; adding a thesis means adding a card to that file. Each card has two attributes used by the filters, data-status and data-tags: 

<div class="box card" data-status="open"
     data-tags="hydrogen les detonation openfoam">
  <div class="card-content">
    <h2 class="title">Parametric LES of a Hydrogen Rotating Detonation Engine</h2>
    <span>~6 months</span>
    <span class="tag">Open</span>

    <div class="thesis-description">
      <p>A short description ...</p>
      <div class="more-text">... the rest, shown with "Read more".</div>
    </div>

    <p><strong>Supervisor:</strong> F. Ghioldi</p>
    <p><strong>Expected outputs:</strong> ...</p>
    <p><strong>Recommended background:</strong> ...</p>
  </div>
</div>

Statuses

data-statusLabelMeaning
openOpenavailable
in-progressIn progressassigned, ongoing
finishedFinishedcompleted
comingComing soonwill open at a given date

Each status has its own colour, set in the stylesheet. Keeping finished theses on the page is useful: they show students what has already been done, and the filter hides them when needed.

Search, filter and counter

Filtering while typing

The search box filters the cards at every keystroke. A card is visible if the text appears in its title, description or tags, and, when the checkbox “Only available theses” is ticked, if its status is open: 

function filterTheses() {
  var query = $("#searchBar").val().replace(/\s+/g, " ").trim().toLowerCase();
  var openOnly = $("#showOpenOnly").is(":checked");

  $("#thesisCardsContainer .card").each(function () {
    var title = $(this).find("h2.title").text().replace(/\s+/g, " ").toLowerCase();
    var desc  = $(this).find(".thesis-description").text().replace(/\s+/g, " ").toLowerCase();
    var tags  = String($(this).data("tags") || "").toLowerCase();

    var queryMatch  = !query || title.includes(query) || desc.includes(query) || tags.includes(query);
    var statusMatch = !openOnly || $(this).data("status") === "open";
    $(this).toggle(queryMatch && statusMatch);
  });
  updateCount();
}

$("#searchBar").on("input", filterTheses);
$("#showOpenOnly").on("change", filterTheses);

Normalising the spaces matters: titles in the HTML are often split over several lines, and without it a search for two words would fail.

The counter

The counter at the top counts the cards with status open: “Theses still available: 7/7”. Theses marked as coming soon are not counted, since they cannot be requested yet.

Filtering from the address

The page also reads a query from the address: theses?q=hydrogen opens the page already filtered. The site search uses this to open a single thesis, and it is handy to send a student a link to a group of theses. 

var q = new URLSearchParams(location.search).get("q");
if (q) { $("#searchBar").val(q); filterTheses(); }

Before the e-mail

Students who want a thesis are asked to fill in a short Google Form before writing, so that the first meeting starts from their background and interests. The header of the page has two buttons: one opens the form, the other (“Apply”) prepares an e-mail with a pre-filled subject. 

<a class="button thesis-form" href="https://forms.gle/..." target="_blank" rel="noopener">
  Before emailing click here
</a>
<a class="button is-primary thesis-apply"
   href="mailto:name@example.com?subject=Requesting%20meeting%20for%20Thesis">Apply</a>

Clicking “Apply” does not open the e-mail directly: a dialog asks whether the form has been filled in. Yes opens the e-mail; No opens the form instead. 

document.querySelector(".thesis-apply").addEventListener("click", function (e) {
  e.preventDefault();
  var mailto = this.href;
  openDialog({
    title: "Before you email me",
    text: "Have you filled in the Google Form before applying for a thesis?",
    yes: function () { window.location.href = mailto; },
    no:  function () { window.open(FORM_URL, "_blank", "noopener"); }
  });
});

One dialog style for the whole website

The dialog has the same design as the one of the “Hire me” button in the left column: a centred panel over a dimmed page, with an icon, a title, a text and buttons. It closes with Esc or a click outside, and gives the keyboard focus back to the button that opened it, so that keyboard users do not lose their place.

Try it yourself

  1. Write three cards with different statuses and tags.
  2. Add the search box and the checkbox, and check the counter.
  3. Open theses?q=<word> and check that the page opens filtered.
